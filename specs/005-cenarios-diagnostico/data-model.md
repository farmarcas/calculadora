# Modelo de dados — cenários

Sem mudança no banco. Os cenários são calculados na hora a partir de: `lojas` (horário por dia, mínimos, convenção, custos), `turnos_atuais` (quadro), `vendas_hora` (base comercial).

Resposta do diagnóstico ganha `cenarios: { r42: Cenarios, r40: Cenarios }` (ver `contracts/api.md`).
